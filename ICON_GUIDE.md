## 🔧 Implementation Guidelines

### Icon Size Classes
```html
<!-- Small icons (sidebar sub-items) -->
<i class="fas fa-icon w-3 h-3"></i>

<!-- Medium icons (sidebar main items) -->
<i class="fas fa-icon w-5 h-5"></i>

<!-- Large icons (page headers) -->
<i class="fas fa-icon text-2xl"></i>

<!-- Extra large icons (welcome cards) -->
<i class="fas fa-icon text-4xl"></i>

<!-- Huge icons (hero sections) -->
<i class="fas fa-icon text-5xl"></i>
```

### Icon with Text
```html
<!-- With margin right -->
<i class="fas fa-icon mr-2"></i>Text

<!-- With margin left -->
Text<i class="fas fa-icon ml-2"></i>

<!-- Centered with text -->
<div class="flex items-center">
    <i class="fas fa-icon mr-2"></i>
    <span>Text</span>
</div>
```

### Animated Icons
```html
<!-- Rotating (loading) -->
<i class="fas fa-spinner fa-spin"></i>

<!-- Pulse -->
<i class="fas fa-heart fa-pulse"></i>

<!-- Hover scale -->
<i class="fas fa-icon transition-transform hover:scale-110"></i>
```

## 📝 Best Practices

1. **Consistency**: Use the same icon for the same action throughout the app
2. **Color Meaning**: Maintain consistent color associations (red = danger, green = success)
3. **Size Hierarchy**: Larger icons for more important actions
4. **Accessibility**: Always include descriptive text or aria-labels
5. **Loading States**: Use spinning icons for loading indicators
6. **Hover Effects**: Add subtle hover effects for interactive icons
7. **Spacing**: Maintain consistent spacing between icons and text (mr-2, ml-2)
8. **Context**: Choose icons that clearly represent their function
