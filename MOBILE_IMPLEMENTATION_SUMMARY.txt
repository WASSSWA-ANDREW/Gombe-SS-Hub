TECHNICAL SPECIFICATIONS
================================================================================

Breakpoints:
- xs: 0px (Mobile)
- sm: 576px (Small Mobile)
- md: 768px (Tablet)
- lg: 1024px (Desktop)
- xl: 1280px (Large Desktop)

Touch Target Minimum: 44×44px (WCAG standard)
Input Font Size: 16px (prevents iOS zoom)
Typical File Size:
- CSS: ~42KB uncompressed, ~12KB gzip
- JS: ~28KB uncompressed, ~8KB gzip
- Total: ~20KB gzip compressed

Browser Support:
- iOS Safari 12+
- Android Chrome 40+
- Microsoft Edge Mobile
- Samsung Internet
- Firefox Mobile

Dependencies:
- None (uses vanilla JavaScript ES6+)
- Tailwind CSS (already installed)
- Font Awesome icons (already installed)

================================================================================
USAGE EXAMPLES
================================================================================

Show/Hide Elements:
→ <div class="hidden-xs d-block-md">Desktop only</div>
→ <div class="show-mobile">Mobile only</div>

Responsive Grid:
→ <div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4">

Touch-Friendly Button:
→ <button class="touch-target py-3 px-4">Tap Me</button>

Show Alert:
→ Mobile.Alert.show('Success!', 'success', 3000);

Open Modal:
→ const modal = new Mobile.Modal(element);
→ modal.open();

Mobile API:
→ Mobile.Modal, Mobile.Dropdown, Mobile.Alert, Mobile.Popover
→ Mobile.initModals(), Mobile.initDropdowns()
